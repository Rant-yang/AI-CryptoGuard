## 审阅者操作

1. 在本机私有目录解压 ZIP，先核对 ZIP SHA-256；按 `README.md` 查看 `MANIFEST.json` 的逐文件摘要。
2. 双击打开 `semantic_review.html`；通过页面文件选择框导入 `v7-review-packet.json`。页面在浏览器本地处理文件，不会自动提交审阅结果。
3. 逐条打开随包附带的**公开源码**，核实四项：用途是否有调用或消费证据、文中 E 编号是否支持对应说法、密码事实是否正确、整改步骤是否可执行。不能只看模型回答就选择“支持”。证据不足填 `false` 并写明理由；未看过保持 `null`。
4. 中途及完成时点击“导出当前审阅 JSON”，保存在私有目录。离开或刷新页面前务必导出；只把导出的 JSON 通过私有渠道交回队长，不提交仓库。

队长收到文件后，从仓库根目录执行：

```cmd
python benchmark\ai_semantic_review.py C:\path\to\returned-review.json --expect-cohort public-crypto-samples-constructor-use-gate-20261019-v7 --expect-sha b8f5e8372457692d5f372918eec80a775050d2f0b68f5ceae113e17338d71212 --require-complete
```

仅在命令确认 `fully_reviewed=29` 后，才能报告该固定批次的人工语义通过率；仍不能称为独立真实项目泛化成绩。有失败项先记录并归因，再修对应扫描证据、AI 判断或规则；修复后另开冻结批次，不能覆盖 v7 的人工记录。
