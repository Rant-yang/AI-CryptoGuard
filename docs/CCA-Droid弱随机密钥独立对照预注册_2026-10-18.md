## 固定范围和标签

评测单位：**一个 Java 源文件是否含可达的 `java.util.Random.nextBytes` 到
`SecretKeySpec` 的密钥字节流**。仅计本项目 `JAVA-WEAK-PRNG-KEY` 配置 Finding；
同文件的 AES/CBC 资产、条件回退或其他 Finding 不计入本专项 TP/FP/FN。
正类 5、负类 2，共 7 个文件；两个模式使用完全相同的匿名源码、jar 和标签。

## 匿名化、运行与评分约定

1. 匿名化 public/helper 类名、包名、文件名；保留 Java 语句和字符串字面量，
   以免改变安全证据。标签和映射不提供给扫描器或 AI。本次不启用云 AI。
2. 用 JDK 17 将同一匿名源码编译一次，供 CrySentry 深扫；失败则报告覆盖率
   而不是把 skipped 当作没有 Finding。
3. 快扫与深扫分别运行。只接受 `deep_java=completed` 的深扫结果；按匿名源文件
   是否出现 `rule_id=JAVA-WEAK-PRNG-KEY` 计算二元 TP/FP/FN/TN。
4. 固定比较：两个模式各自的 Precision、Recall、F1，CrySentry pattern/taint
   证据数、新增真阳性/误报、未挂载线索数和深扫耗时。若某侧无正预测，
   Precision 记为 `null`，不能写成 100%。
5. 该 7 文件专项只检验弱随机密钥流，不是完整产品的全系统 P/R，不能与
   25 例 CryptoAPI-Bench 或 482 例 OWASP 的不同计数单位混算。

首次扫描命令和不可变输出摘要将在**预注册提交之后**另行记录。
